# [Installation](../installation/) · [CUDA 12.8]

This guide walks you through installing the project directly on your machine. If you have newer‑generation hardware or prefer an isolated, reproducible environment, you can instead use [Docker 🐳](docker/README.md).

## Prepare prerequisites

- Only Linux
- Only gcc/g++ 9; otherwise, errors will occur later in some builds.
- Only [CUDA 12.8](https://docs.nvidia.com/cuda/cuda-installation-guide-linux/) & [cuDNN 9.x](https://docs.nvidia.com/deeplearning/cudnn/latest/installation/linux.html)
- Only Python 3.11 -> `conda create --name bevfusion python=3.11`

## Install requirements and build

- From here, you must switch to gcc/g++ 9, and activate your conda environment:

  ```bash
  conda activate bevfusion
  ```

- Install `opencv-python` and `numpy`:

  ```bash
  pip install pip wheel "setuptools<82"  # MUST DO !!!
  pip install numpy==1.26.4 "opencv-python<4.12"
  ```

- Install [PyTorch](https://pytorch.org/) 2.11.0 + CUDA 12.8 (Max support: `compute_120`, `sm_120`):

  ```bash
  pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
  ```

- Install [OpenMPI v4.0.7](https://www.open-mpi.org/software/ompi/v4.0/) (CUDA):

  <details><summary>Show more details</summary>

  - Clone source:

    ```bash
    cd ~
    wget https://download.open-mpi.org/release/open-mpi/v4.0/openmpi-4.0.7.tar.gz
    tar -xvf openmpi-4.0.7.tar.gz
    ```

  - Config cmake with CUDA:

    ```bash
    cd openmpi-4.0.7
    ./configure --prefix="/home/$USER/.openmpi" --with-cuda=/usr/local/cuda
    ```

  - Build and install:

    ```bash
    make -j$(nproc)
    make install
    ```

  - Add environment variables in `.bashrc`:

    ```bash
    export OPENMPI_HOME="$HOME/.openmpi"
    if [ -d "$OPENMPI_HOME" ]; then
        export PATH="$OPENMPI_HOME/bin:$PATH"
        export LD_LIBRARY_PATH="$OPENMPI_HOME/lib:$LD_LIBRARY_PATH"
    fi
    ```

  - Quick test:

    ```bash
    ompi_info
    ```

  </details>

- Install [MMCV v1.7.4](https://github.com/rathaROG/mmcv/releases/tag/v1.7.4-bevfusionx) with CUDA:

  ```bash
  pip install --extra-index-url https://rathaumons.github.io/bevfusionx-index/cu128/ mmcv-full==1.7.4
  ```

- Clone the repo and install Python packages:

  ```bash
  cd ~  # or choose your preferred location
  git clone -b v1.3.0-bevfusionx https://github.com/rathaumons/bevfusionx.git
  cd bevfusionx
  pip install -r extra_reqs.txt
  ```

- Install custom [`cumm`](https://github.com/rathaROG/cumm-gpu) and [`spconv`](https://github.com/rathaROG/spconv-gpu) with CUDA 12.8:

  ```bash
  pip install --extra-index-url https://ratharog.github.io/cumm-spconv/ cumm-cu128==0.9.1
  pip install --extra-index-url https://ratharog.github.io/cumm-spconv/ spconv-cu128==2.4.1
  ```

- Install `flash-attn==1.2.1` and `setuptools==59.5.0`:

  ```bash
  pip install --extra-index-url https://rathaumons.github.io/bevfusionx-index/cu128/ flash-attn==1.2.1
  pip install setuptools==59.5.0
  ```

- Build `bevfusion`:

  ```bash
  python setup.py develop
  ```

  <details><summary>Show more details</summary><br>

  From version 1.2.0, you can fully control CUDA architecture selection from the terminal when building extensions:

  - Full control: Use the `BEVX_CUDA_ARCH_LIST` environment variable to specify custom architectures (e.g., "8.9;12.0"; see [`nvidia-arch`](https://github.com/rathaROG/nvidia-arch) docs for syntax). For example, for normal consumer GPUs from **NVIDIA RTX 4000/5000** series and **NVIDIA DGX Spark**:

    ```bash
    BEVX_CUDA_ARCH_LIST="8.9;12.0;12.1+PTX" python setup.py develop
    ```

  - Filtered auto-detection: Use `BEVX_GPU_TYPE` to specify the GPU type (`gpu_type`) and `BEVX_MIN_SM` to set the minimum SM number (`min_sm`) for auto-filtering via the [`nvidia-arch`](https://github.com/rathaROG/nvidia-arch) package. For example, for Data Center GPUs from **NVIDIA T4, A100, H100, ...** to **NVIDIA RTX PRO 6000 Blackwell Server Edition**:

    ```bash
    BEVX_GPU_TYPE=dcen BEVX_MIN_SM=75 python setup.py develop
    ```

  </details>

- Check the main [README.md](https://github.com/rathaumons/bevfusionx#readme) for information on preparing datasets, running evaluations, training models, and visualizing results.
